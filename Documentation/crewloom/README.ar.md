# ذاكرة المشروع داخل Git

> **نموذج أولي مجمد.** منذ 2026-10-29 لا يُطوَّر هذا الأمر الأصلي، والعمل الجديد
> طبقة ذاكرة فوق Git المثبت كما هو. السبب والخطة في
> [IMPLEMENTATION-PLAN.md](../../IMPLEMENTATION-PLAN.md) و[الخطة العربية](plan.ar.md).

هذه ميزة تجريبية في فورك Crewloom من Git 2.56.0. تضيف تاريخًا محليًا خاصًا
لتغييرات الملفات التي يختارها المستخدم، وتُبقي محتوى الفهرس staged ومحتوى ملفات
العمل منفصلين. التنفيذ محلي وحتمي، ولا يحتاج نموذج ذكاء اصطناعي لالتقاط التغييرات
أو تخزينها أو حساب الفروق أو استرجاع المقتطفات.

## البناء والتشغيل

من جذر مستودع المصدر:

```sh
./scripts/build-memory.sh
./git memory init --worktree -- src core
./git memory watch
```

يبدأ `init` الذاكرة بعد اختيار نطاق صريح من المسارات المتتبعة. `watch` يعمل في
المقدمة ويلتقط التغييرات المحفوظة أثناء تشغيله. لإيقافه استخدم Ctrl-C. الأمر
`git memory context --query tax` يعيد سياقًا محدودًا من آخر لقطة محفوظة ويحدّثها
أولًا؛ أضف `--no-refresh` لقراءة اللقطة المحفوظة فقط. أوامر `status` و`history`
و`diff` و`note` موضحة في [صفحة الدليل الإنجليزية](../git-memory.adoc).

الأداة المبنية هي `./git` داخل هذا المستودع؛ البناء لا يستبدل Git النظام.
ذاكرة كل worktree منفصلة، والذاكرة معطلة قبل `init`. لا تُضاف الملفات غير
المتتبعة. لا تستخدم نطاقًا يحوي أسرارًا: نسخ المحتوى الخام تبقى في تاريخ المخزن
حتى بعد حذف الملف من شجرة العمل. فحص الأسماء الحساسة محدود وليس ماسح أسرار شاملًا.

## حدود المعرفة ونسب التغيير

يحفظ Git البايتات والتوقيت الذي رُصدت فيه اللقطة. يمكن للـhost تمرير actor وmodel
وsession وtask، لكن هذه قيم معلنة وليست هوية موثّقة؛ إذا لم يمررها، تُسجّل
`unknown`. لا يستطيع المراقب تحديد أي موديل غيّر ملفًا خارجيًا، ولا يضمن التقاط
تعديل عابر بين دورات المراقبة. ثبات الملفات المذكورة في ملاحظة لا يثبت صحة الملاحظة
ولا اكتمال تبعياتها.

السياق يتضمن مقتطفات ومصادر وحدود بايتات ضمن سقف JSON صريح. لا يوجد تحليل
Tree-sitter أو رسم اعتماديات دلالي، ولا قياس فعلي لتوفير الكوتا أو زيادة الذكاء.
راجع [حدود الميزة وتفاصيل الأمان](../git-memory.adoc) و[قرار المجلس والخطة](../../IMPLEMENTATION-PLAN.md).

## التحقق المحلي

```sh
./scripts/build-memory.sh DEVELOPER=1
./scripts/test-memory.sh
```

المتأثرة. نتائج الإصدار المنشور تُوثق في `RELEASE-NOTES.md` بعد تحقق CI.
